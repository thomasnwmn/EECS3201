## Lab 4
In this lab, we had to use memory circuit elements, such as the RS Flip Flop to design a NBA shot clock.  On the seven segment display, it would start with either 24 or 30 seconds, and count down to zero.  There is a reset button to set it back to the initial value, and also a pause button to stop and hold the count.
## Lab 3
In this lab, we were tasked with creating a module that implements a full adder, and then combine four of those modules to implement a four-bit ripple-carry adder.  Not only did it need to be able to add 2 four-bit integers together, but also minus them by flipping a switch.  the two integers were displayed on 2 different seven-segment displays, and then the result was displayed on the rightmost display.  If the result was negative, the second to the rightmost display also displayed a negative sign, and if it was a two digit hexadecimal number, then it also could display a 1 there.
## Lab 2
In this lab, we kicked things up a notch.  This was the first lab where we actually needed to use the DE10 Lite board, where we initialize the seven-segment display and write a hexadecimal digit to the screen using four of the onboard switches.  From right to left, the four switches would represent a four bit binary number, going from 1-F.
## Lab 1
In this lab, the professor tasked me with writing an extremely basic circuit in Verilog, since it was my first program.  It was a basic NAND gate in a module, just to teach some basic syntax like modules, and assigning an output.
